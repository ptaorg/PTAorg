# PTA適正化推進委員会 拡張型スターターサイト

## 概要
GitHub Pagesにそのまま置ける静的サイトです。Reactは使わず、HTML/CSS/JS/JSONで構成しています。

## 更新方法
1. `data/records.json` に資料を追加
2. `pages/database.html` で自動検索表示
3. 必要に応じて個別ページを追加

## 分類
- A: 適正分離
- B: 委任・依頼継続
- C: 資料確認中
- D: 高リスク
- N: 未判定

## 重要方針
覚書・委任状・契約書の存在は、学校関与の正当性を当然に意味しません。存在確認と法的評価を分けて扱います。
